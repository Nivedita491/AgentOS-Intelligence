## How to apply (manual, on GitHub)

1. Open the repository on GitHub.
2. Click the **gear icon (⚙)** in the **About** panel on the right side of the repository landing page.
3. Paste the **Description** text above.
4. Paste the **Topics** (comma-separated or space-separated) above.
5. Paste the **Demo URL** into the Website field.
6. Save.

No automated script is provided because this repository does not include authenticated tooling for GitHub API mutations, and manual application is the safest path.
